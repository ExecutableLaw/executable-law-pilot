# Provenance

## Code that ran

The nine Python modules in `src/` are byte-identical to the files executed for the Title 47 pilot on
2026-11-23 (06:07 to 09:53 UTC). `configs/run_code_sha256.txt` lists their SHA-256 hashes, and
`tools/verify_cpu.py` checks them. The Title 21 run (2026-11-24) used the same files; its runner refuses to start if
`prompts.py`, `scoring.py`, `el_core.py`, `infer.py` or `sft.py` differ from those hashes.

Usage examples in some module docstrings mention `/data/...`; these are the mount points of the original GPU machine
and were left in place so the hashes still hold.

The machine-specific shell scripts that drove the stages on the GPU machine (environment activation, fixed paths and
artifact syncing) are not included. `tools/run_pilot.sh` runs the same commands and settings, recorded in
`configs/*.json`, from the repository root on any single-GPU machine.

## Configurations

`configs/` holds the exact command line, data file, LoRA settings and effective trainer arguments for every training
run (`sft.json`, `sft_all.json`, `grpo_R1.json`, `grpo_R3.json`), every evaluation command and decoding setting
(`eval.json`), and the saved PEFT adapter configs (`configs/lora/`). Training-machine paths in these files were
rewritten to the relative `models/...` form.

## Data

- `data/splits/` holds the exact Title 47 splits used. The data-matched control trained on `sft.jsonl` followed by
  `rl.jsonl` (772 examples); that concatenation is regenerated by `tools/run_pilot.sh sft_all` rather than stored.
  `rl_prompts.jsonl` is the 175-prompt GRPO set chosen by the 8-sample prefilter in `results/rl_prefilter.jsonl`.
- `heldout/t21/` holds the frozen Title 21 sets, with input and output hashes and build counts in `manifest.json`
  and the train/test overlap audit in `overlap.json`.
- Instructions and section text are U.S. Federal Register and eCFR text retrieved from the public
  federalregister.gov and ecfr.gov APIs by `src/build_data.py`. Rebuilding against the live APIs today can return
  different versions; the stored splits are the reference.

## Outputs

- `results/test_*.jsonl`: one line per test item with the item id, exact-match result `z`, validity, abstention,
  stated confidence and the generated text, for every evaluated Title 47 model; `*.summary.json` is what `infer.py`
  wrote, and `REPORT.json` is the output of `src/report.py`.
- `results/rl_prefilter.jsonl`: 8 samples per RL-pool prompt from the SFT model (scores for all 8, first 2 texts).
- `results/training/`: per-step SFT loss, GRPO trainer logs and every GRPO reward (`reward_log.json`).
- `results/bf16_visibility_R*.json`: share of weights a bf16 merge of each GRPO adapter would change.
- `results/title21/`: Title 21 predictions, the two paired reports and `provenance.json` (adapter and control
  weight hashes, frozen-input hashes, environment). `title47_rerun/` holds the Title 47 rebuild check.

|---|---|---|
| `sft_adapter` (LoRA r 64, fp32) | `Qwen/Qwen3-1.7B` | `c1d099b8edf5c44c7a2903d5a8aea164b0845482e58076c89a5233597ede4942` |
| `grpo_R1_adapter` (LoRA r 32) | `models/sft` = Qwen3-1.7B with `sft_adapter` merged in bf16 | `cb410d775e0cdc68cf096e45cb18cc3a85b3694d4bbc13f41aa76807d5ba2fd0` |

`tools/rebuild_sft_merged.py` rebuilds `models/sft` from `sft_adapter`; the Title 47 rerun shows the rebuild plus
`grpo_R1_adapter` reproduces the pilot's 124/179. The pilot's merged SFT weights and its original data-matched
control (`sft_all`) were not kept; the Title 21 run retrained the control (merged weights SHA-256
`6241a1990d6d9a423d3953ed59d314039ef49bbe23f43390760b63d12946ddaf`).

## Not included

Raw stage logs and console output (progress bars and warnings; every number they contain is in the summaries and
training logs), the full package freeze of the Title 21 machine (key versions above), a copy of the Qwen3 tokenizer,
and the sample XML files used while writing the parsers. In the pilot's stage log one stage is marked failed only
because a post-stage artifact sync found no model directory; all four baselines completed and their outputs are here.
